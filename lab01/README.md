## Структура каталога

- `specs/` — spec-файлы пакетов
- `sources/` — исходные файлы пакетов
- `env/` — описание сборочного окружения (репозитории, пакеты, конфигурация hasher)
- `logs/` — журналы выполненных команд
- `check/` — сценарий проверки и эталоны

_Отчёт заполняется по ходу выполнения работы._
